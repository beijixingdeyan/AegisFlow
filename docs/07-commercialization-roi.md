# 07 · 商业化路线图、ROI 模型与销售场景

> 对应需求文档 Phase 2 第 9 节 与 硬性约束「商用价值」。做一个真实、可量化、可售卖的
> 安全产品，而非演示代码。

---

## 1. 解决的痛点与用户画像（付费意愿）

- **痛点**：告警疲劳（分析师淹没在海量误报）、未知攻击检测失效（规则 SIEM 盲区）、
  AI 黑盒不可审计（无法过合规）、响应慢（MTTD/MTTR 长导致损失放大）。
- **付费画像**：
  - **CISO**：要风险可见、合规达标、MTTR 缩短（预算充足，是最终买单人）。
  - **SOC Lead / 分析师**：要减负、可解释、能放进工作流（体验决策者）。
  - **DevSecOps**：要自动化响应、API、与现有栈集成（渐进式采用的关键入口）。
  - **合规官**：要审计、不可抵赖、等保/ISO/SOC2 支撑（售前合规关卡）。

---

## 2. ROI 模型（可量化）

### 2.1 节省人力（SOC 分析师工时）
- 假设中大型 SOC：每天 ~5000 条原始告警，其中 95% 为误报/重复。
- 现状：分析师人均每天处理 ~100 条，需 **50 分析师** 处理 5000 条。
- AegisFlow 智能降噪：收敛为每天 ~10 条高优先事件 + 归并，分析师只需处理 10 条。
- 需要分析师 ≈ 10（含复核）。
- **节省 ≈ 40 分析师 × 年薪 ~60 万 = 年省 ~2400 万元**（规模化的直接人力成本）。

### 2.2 减少损失（MTTD/MTTR 缩短 → 风险降低）
- 行业基准：平均数据泄露成本 ~440 万美元(IBM 2023)；每次事件平均响应时间 ~277 天。
- AegisFlow 把 **MTTD** 从「天」降到「秒~分钟」（实时行为检测），把 **MTTR** 从「天」降到
  「分钟」（自动化响应：撤销会话/断网/隔离 <500ms）。
- 假设年 3 次高危事件，每次因 MTTD/MTTR 缩短而减少损失 20%：年减损 ~ 3 × 440万 × 20% ≈ **264 万美元**。

### 2.3 合规价值（审计成本降低）
- 自动生成不可篡改审计链 + 策略快照，显著减少等保/ISO27001/SOC2 审计的人工取证时间
  （从「周」级取证降到「天」级），降低不合规罚款与审计顾问费用。

---

## 3. 渐进式采用（不能要求一次性替换现有安全栈）

- **切入点 1（Identity 行为检测）**：先接身份认证/SSO 日志，跑通「行为基线+异常+响应」最小闭环，
  与现有 SIEM/EDR **并存**。
- **切入点 2（端点行为）**：接 EDR/终端遥测，扩展检测面。
- **切入点 3（云/网络）**：接云 Trail / 网络流。
- 全程通过开放 API 与现有栈集成，**按需扩展**，不强制替换。

---

## 4. 销售场景

- **POC 模式**：交付可运行 demo 镜像 + 合成/样本数据 + 一周内出报告（检测出几条真实异常、ROI 测算）。
- **免费试用层**：SaaS 版一定 EPS 内的免费额度（如 ≤5k EPS、1 tenant），用于自下而上的增长。
- **企业级 SLA**：99.99% SLA、私有化支持、专属客户成功、合规文档包。
- **渠道**：通过 MSSP / 云市场（阿里云/华为云）分发私为标准。

## 5. 路线图

| 阶段 | 时间 | 目标 | 范围 |
|------|------|------|------|
| MVP | ~2 个月 | 可演示、解决一个痛点 | Identity 行为检测 + 智能降噪 + 可解释 + 合成数据 demo |
| V1.0 | ~6 个月 | 单客户生产可用 | 端点/云接入、自动化响应（approve 模式）、外部 KMS、mTLS 全网 |
| V2.0 | ~12 个月 | 规模化、多租户 | 纯 SaaS 多租户、混合云、MLOps 模型版本化、完整合规包 |

**本仓库状态**：已实现 **MVP+ 核心**（检测引擎、降噪、可解释、响应、mTLS、审计、RBAC/ABAC、
加密、三种模式配置），可作为 V1 工程的地基。

## 6. 定价模型与竞品对比

- **模型**：混合 —— 订阅（管理平面 + 分析席）+ 按量（检测 EPS）+ 企业 License（私有化）。
- **示意定价（供对标估算，非最终）**：
  - Starter：¥xx 万/年起，≤10k EPS。
  - Business：¥xx 万/年，≤100k EPS，含高级响应。
  - Enterprise：定制 License（私有化 / 混合云 / SaaS 专属）。
- 与竞品相比，AegisFlow 的核心差异化定价依据是**「可解释 + 降噪 + 合规」**三者兼得，
  而非单纯比价。

> 标注：ROI 数字为基于行业基准的估算模型，用于商务演示，不构成财务承诺。
